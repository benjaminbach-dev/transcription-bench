{# Composant compact de résultat, partagé (tâches 1.3 et 1.4, design D2, D3 et D6). Fichier de macros, sans page propre : `resultats.html` l'emploie par `groupe_resultats`. Les mappings viennent de `web/vues_resultats.py`. Contrat de `resultat_compact(resultat)` : un mapping ou un objet portant `modele`, `lien` (adresse du détail, facultative), `moteur`, `date_essai` (ISO ou absent), `variante`, `indicateurs` (durée de transcription, pic mémoire, occupation CPU, temps CPU : `IndicateursAudio` ou mapping de mêmes clés), `annotation_ram`, `materiel_alerte`, `etats` (libellés courts) et `duree_audio` (libellé facultatif, seulement si les durées d'un groupe divergent). Tout champ absent donne « non consigné » ou « non mesuré » ; une valeur invalide donne « indisponible » par les formateurs de `indicateurs_resultats`, jamais zéro. Disposition : une ligne par essai. Sur bureau, le modèle occupe la colonne de gauche et les cinq valeurs (temps, RAM, CPU, moteur, date) se suivent à droite ; en petit écran, tout se replie en blocs étiquetés, sans défilement horizontal. La case de sélection éventuelle précède le modèle dans la même ligne. Le pic mémoire est un pic cumulatif du moteur quand `annotation_ram` est renseignée : seule la mention courte « pic cumulatif » s'affiche, l'explication complète restant dans l'aide locale et le détail. `distinction_temps` et `distinction_ram` (facultatives) portent le libellé court d'une meilleure mesure observée (« meilleur temps », « meilleure RAM », égalité comprise). Le libellé reste près de la valeur, prend sa couleur d'accent et ne remplace jamais la mesure ; le CPU n'en reçoit aucune. `entete_groupe_audio` donne le titre d'un groupe par empreinte : nom du fichier, durée décodée commune ou mention de durées divergentes, et empreinte courte pour distinguer deux fichiers de même nom. L'empreinte complète reste dans un détail. Jamais la durée d'un lot. Une ligne reçoit en plus une case de sélection quand le mapping porte `case` (page Comparaisons) : nom du champ, valeur `exécution:ordre`, libellé accessible et état coché. La case reste dans la cellule du modèle, sans colonne technique ni second formulaire. Contexte de l'ordinateur (tâche 3.1, design D4) : `aide_contexte_ordinateur`, `valeurs_audio` et `valeurs_chargement` composent, dans les pages de détail et de comparaison, un bloc secondaire repliable, fermé par défaut et sans JavaScript, avec une entrée par audio. Il n'expose que les observations système relues (`ObservationSystemeVue`) : CPU total moyen pendant l'audio, RAM disponible après l'audio avec la capacité totale du même instant, et RAM disponible après chargement. Aucune valeur n'est déduite des indicateurs du moteur : ni marge mémoire par différence avec le pic, ni part « autres applications », ni minimum resté disponible. Une observation absente, écartée à l'écriture, invalide ou d'une version inconnue affiche « non mesuré », son motif restant au second niveau ; une observation simulée est marquée comme scénario et sa date constante n'est jamais présentée comme un relevé réel. Les valeurs brutes (octets, pourcentage, intervalle, méthode et version psutil, instant du relevé) restent au second niveau repliable, sans les trois décimales du premier niveau ; le libellé repliable porte le qualificatif de son relevé (« après l'audio », « après le chargement du modèle ») pour distinguer des blocs répétés. Les titres des entrées et les valeurs système portent les classes discrètes `resultat-contexte-titre` et `resultat-valeur-systeme` (corps réduit), jamais la taille des mesures du moteur. L'aide du bloc reste courte : les autres programmes inclus et l'instantané pris après l'audio y sont dits une seule fois, le texte complet des limites vivant dans la page d'aide locale (`aide_resultats.html`, design D4). #} {% macro resultat_compact(resultat) -%} {%- set case = resultat.case | default(none) -%} {%- set indicateurs = resultat.indicateurs | default({}, true) -%} {%- set duree = indicateurs.duree_transcription_s | default(none) -%} {%- set pic = indicateurs.pic_memoire_octets | default(none) -%} {%- set occupation = indicateurs.occupation_cpu | default(none) -%} {%- set temps_cpu = indicateurs.temps_cpu_s | default(none) -%} {%- if occupation is not none -%} {%- set cpu = formater_pourcentage_premier_niveau(occupation) -%} {%- elif temps_cpu is not none -%} {%- set cpu = "non interprétable" -%} {%- else -%} {%- set cpu = "non mesuré" -%} {%- endif -%} {%- set temps_affiche = formater_duree_premier_niveau(duree) -%} {%- set ram_affichee = formater_memoire_premier_niveau(pic) -%} {%- set distinction_temps = resultat.distinction_temps | default(none) -%} {%- set distinction_ram = resultat.distinction_ram | default(none) -%} {%- set absences = ("non mesuré", "non interprétable", "indisponible") -%}
