Un modèle prêt est un dossier local complet, vérifié à une révision figée ; un dossier incomplet, interrompu ou sans inventaire cohérent n'est jamais proposé. L'ajout commence par vérifier un dépôt : seules les métadonnées et les petits fichiers de configuration sont lus, aucun poids n'est téléchargé, et le téléchargement reste une action explicite exécutée seule dans le créneau d'opération longue. La suppression retire les fichiers locaux du modèle ; les transcriptions et mesures déjà consignées ne sont pas modifiées.
